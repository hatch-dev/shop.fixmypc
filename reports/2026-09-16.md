# Daily Report — 16 Sep 2026

**Focus:** VAT correctness end to end, order record integrity, and admin order management.

## VAT / pricing
- Added a single VAT split helper (`Pricing`) covering both conventions — Ex-VAT prices get VAT added, Inc-VAT prices get it taken out — and wired every surface through it: product page, listing tiles, cart, checkout, payment, order detail, confirmation, invoice PDF and order emails.
- Mixed baskets (Ex-VAT and Inc-VAT lines together) now normalise to net before aggregating, so the gross summary closes.
- Quantity-band / business pricing corrected at the boundaries: crossing a threshold moves the price *and* its VAT split together; personal accounts are never banded.
- Added `InfoPopover` so the VAT basis is explained in place on mobile and desktop.

## Order record
- 4 migrations: customer snapshot on `orders` (account type, company, VAT no., CRO no.), `paid_at`, soft deletes, and `tax_rate` / `tax_inclusive` on `ordered_products`.
- Orders now state the VAT that was actually charged, not whatever the product's tax rule says today. A placed order no longer moves when the catalogue, the tax rule or the customer's account changes.
- `BackfillVatTreatment` command for historic rows — it sorts each line into corroborated / assumed / contradicted and refuses to guess, rather than silently stamping today's rate on old orders.

## Admin
- Order list: payment-state and method filters fixed, per-customer narrowing, delete/restore with an audit trail of who did it, and the N+1 removed (query count no longer grows with order count).
- Order detail: account type read off the order, PO number surfaced, per-line list price and discount shown, legal status moves enforced and logged.
- Stopped the whole user record being serialised into admin order payloads.

## Cart stability
- Server-decided money (price, VAT split, line totals) is now stripped from the persisted basket on rehydrate. This was the cause of "VAT €0.00" under a correct Products Total on the payment page — old snapshots restored into a newer build.

## Testing
- 10 Laravel feature test files, 102 tests, covering VAT breakdown, mixed baskets, repricing, band boundaries, listing prices, order confirmation fidelity and the admin order screens.
- 8 headless JS checks for the frontend/admin components, plus 4 verification scripts that compare the same order across checkout, confirmation, admin and invoice.
